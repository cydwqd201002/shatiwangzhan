## 为什么做这个

社团招新、期末复习、课程自测的场景里，题目几乎总是躺在 Word、PDF、公众号文章或者 Excel 表里。想真正「刷」起来，困难不在于题目，而在于：

1. **没法判分** —— Word / PDF 里的题目只能看，不能点选项、不能自动对答案，对答案靠人工翻页比照。
2. **现成的刷题 App 门槛太高** —— 要么强制注册登录、把题库上传到别人的服务器，要么只接受它自己的固定格式，还有付费墙。
3. **刷完没有闭环** —— 错了的题不记得、不重练；正确率全凭感觉，看不出哪一章真的薄弱。
4. **不会的题当场卡住** —— 解析看不懂，也没办法追问。

这个项目只解决一件事：**让「手里任何一份题库」在 30 秒内变成可以判分、可以复盘、可以追问的练习**，而且数据完全留在本地。

## 功能总览

### 题库

- **多格式导入**：JSON、TXT / Markdown、CSV、Word(.docx)、Excel(.xlsx)、PDF（文字版）
- **内置题库**：仓库版本内置 Java 程序设计题库（219 题）与 Web 前端题库（120 题），开箱即用
- **题库管理**：卡片式列出题库、题量、章节数、单选 / 多选 / 判断分布、完成进度环，可删除自建题库
- **示例与说明**：一键下载 TXT 题库模板，内嵌格式说明弹层（TXT/MD 规则、CSV/Excel 表头、JSON 结构）

### 练习

- **7 种练习模式**：顺序练习、随机练习、章节练习、只做未做、错题重练、收藏重练、模拟考试
- **灵活组卷**：按章节 / 知识点筛选，题量可选全部、20、50、100，可打乱顺序、可按难度排序
- **边做边判 or 考试模式**：练习模式即时判分并给解析；考试模式中途不透露对错，交卷后统一判分
- **限时交卷**：5 / 10 / 20 / 30 / 45 / 60 / 90 / 120 分钟，时间到自动交卷
- **断点续做**：每答一步自动存盘，关窗口、换页面、刷新都不丢；首页可「继续上次」

### 复盘

- **错题本**：错题按轮次分组，可「重练本轮」或「重练全部」；答对自动移出错题本
- **重点收藏**：先自己回忆，再手动展开答案与解析
- **成绩记录**：每轮题量、用时、正确率、分题型表现；手写 SVG 正确率曲线（最近 12 轮）
- **学习建议**：根据最近几轮自动提示进步 / 回落，并指出最薄弱章节
- **成绩对比**：上传他人的 JSON 备份做本地对比（文件不上传服务器）
- **搜题**：题干 / 选项 / 解析模糊检索，支持错字与子序列匹配，可开启无痕搜索

### 个性化与体验

- **8 套主题**：跟随系统、浅色、深色、海盐蓝、森林绿、樱花粉、午夜紫、高对比
- **界面自定义**：缩放 85%–120%、内容透明度、按钮间距、主色、背景色、背景图、字体、导航与快捷入口顺序
- **8 条环境音**：静心音、细雨、森林气息、夜航、海浪、壁炉、呼吸、午后微光（浏览器实时合成，无需下载音频），也支持上传自己的音频
- **番茄钟**：任意页面显示倒计时，专注 / 休息自动切换；连续做题 2 小时主动提醒休息
- **日落后提醒**：进入傍晚询问是否切换深色（按月份估算，不申请定位权限）
- **防眩晕模式**：关闭动画、渐变与阴影，适合车上或容易眩晕时使用
- **键盘操作**：`A–H` / `1–8` 选选项、`Enter` 提交、`←→` 切题、`S` 收藏、`M` 切主题
- **移动端适配**：底部固定操作栏、刘海屏安全区、最小触控尺寸、滑动切题

### AI 答疑（自带 Key）

- 在答题页对任意题目点「问 AI」，模型会结合题干、选项、正确答案、原有解析给出讲解
- 支持 DeepSeek、OpenAI 以及任意兼容 OpenAI Chat Completions 的中转地址
- Key 只保存在本机浏览器，不随数据备份导出，也不会发给本站服务器
- AI 只做讲解，**不参与判分**；回答固定标注「仅供参考，请结合教材与题目解析判断」

### 激励与本地账户

- **积分中心**：答对 +2 分、完成一轮练习按正确率给奖励、每日签到 +5 分
- **称号体系**：初来乍到 → 勤学书生(100) → 题海行者(250) → 知识猎手(500) → 学霸之光(900) → 传奇题神(1500)
- **积分解锁主题**：薄荷清风(60)、极光(120)、落日熔金(200)、赛博霓虹(320)、星河漫游(500)
- **本地多账户**：可建多个本地账户各存一份数据；用户名 + 密码只保存在本机，换设备不同步

### 数据治理

- **数据体检**：前端实时扫描题库，识别缺答案、无选项、选项不足、选项重复、答案不在选项内、无解析、题干重复 7 类问题
- **可撤销的标记**：异常题可「一键移出练习」，只写本地标记，不改动任何原始题目内容，随时可撤销
- **导出 / 导入 / 清理**：JSON 备份下载、系统分享、剪贴板复制；按时间范围与轮次批量清理错题、收藏、成绩、搜题记录
- **用户测试面板**：7 个真实场景任务自动打勾 + 5 档评分与建议表单，反馈随备份一起导出

## 题库格式

### TXT / Markdown / Word / PDF（同一套容错解析）

```markdown
### 1. 单选题
题干可以换行，也支持 ```代码块```。

- A. 选项一
- B. 选项二
- C. 选项三
**答案**：B
**解析**：可选。

### 2. 多选题
- A. 选项一
- B. 选项二
- C. 选项三
**答案**：A、C

### 3. 判断题
不写选项也可以，答案写「正确 / 错误」。
**答案**：正确
```

### CSV / Excel（优先识别表头）

```csv
序号,题干,A,B,C,D,答案,解析,章节
1,1+1 等于多少？,1,2,3,4,B,基础加法,第一章
```

### JSON

```json
{
  "title": "我的题库",
  "questions": [
    { "stem": "1+1 等于多少？", "options": ["1", "2", "3", "4"], "answer": "B" }
  ]
}
```

说明：

- 判断题答案支持「正确 / 错误 / 对 / 错 / √ / × / T / F」等写法，统一映射为 `A` / `B`
- PDF 只支持文字版；扫描件（图片型 PDF）需先做 OCR。PDF 解析组件按需在线加载，首次使用需联网
- 旧版 `.doc` / `.xls` 请先另存为 `.docx` / `.xlsx`
- 单文件上限 20 MB；导入后题库只存本地

### 内置题库是怎么生成的

仓库版本的内置题库由 `tools/build_data.pl` 从两份 Markdown 题库转换而来：

```bash
perl tools/build_data.pl [题库目录] [输出目录]
```

脚本会输出 `js/data/banks.js`、`data/banks.json` 和一份 `data/build-report.md` 转换报告，逐题校验并登记异常（缺答案、答案为 E 但选项只有 ABCD、题干重复等），**题目内容一律原样保留、不做修正**；影响判分的题目会标为「不计分」，但仍然可以查看和作答。当前内置 339 题中可判分 336 题，异常 6 条记录在 `data/build-report.md` 里。

```
打开网站
  │
  ├─ 已有题库 → 首页题库卡 → 选择练习方式（章节 / 题量 / 顺序 / 是否限时）

```

答题过程中每一步都会自动存进浏览器，中途关掉页面下次打开会看到「继续上次」卡片。

## 技术说明

### 无构建、无框架、无依赖

全站只有一个 `index.html`，3 个 CSS + 22 个 `<script>` 顺序加载，没有打包器、没有 npm 依赖、没有 `import/export`。所有模块挂在一个全局命名空间 `window.HZQ` 下：

```
QUIZ_DATA → util → grading → data → store → engine → i18n / comments / audio / profile → views → app
```

最后一个内联脚本定义 `HZQ.app`，只负责路由、会话、主题与搜题，业务规则全部在 `core/` 里。

### 三条硬约束

1. **判题只有一处实现**（`js/core/grading.js`）。单选、判断走单值比较，多选必须完全一致才得分（不给部分分），数据异常题统一返回 `na` 不计分。任何页面都不得另写一套判分逻辑，否则同一道题在不同页面会出现两种结果。
2. **分数是「算」出来的，不是「累加」出来的**。`engine.stats()` 每次都遍历答案重新统计，重复提交只增加尝试次数，不会把分数越加越高。
3. **持久化只有一处出口**（`js/core/store.js`）。整体存成一份 JSON，键名 `hqz.v1.db`；读写失败时降级为内存模式并提示用户，不会静默丢数据。

### 数据模型（localStorage）

| 键 | 内容 |
|---|---|
| `hqz.v1.db` | 设置、单题进度、错题本、收藏、成绩记录、搜题历史、体检标记、会话快照、积分与称号 |
| `hqz.userBanks.v1` | 用户上传的题库（线上版本） |
| `hqz.ai.v1:guest` / `hqz.ai.v1:<账户>` | AI 服务配置（含 Key，不随备份导出） |
| `hqz.comments.v1` / `hqz.commentName.v1` | 题目讨论与昵称 |
| `hqz.profiles.v1` | 本地账户（用户名 + 加盐摘要 + 各自的数据快照） |
| `hqz.audioCustom.v1` | 自定义环境音 |

### 其他实现要点

- **路由**：手写 hash 路由（`#/bank/:id`、`#/quiz/:id` 等），`hashchange` 触发渲染，渲染前先 `unmount()` 旧视图
- **主题**：`<html data-theme>` + CSS 变量；`index.html` 头部内联脚本在 CSS 之前读取上次选择，避免深色模式闪白
- **可访问性**：跳转链接、`aria-current` / `aria-pressed` / `aria-modal`、`:focus-visible` 焦点环、`prefers-reduced-motion`、移动端 42–48px 触控尺寸
- **文档解析**：`.docx` / `.xlsx` 用浏览器内置 `DecompressionStream('deflate-raw')` 自行解 ZIP 后读 XML；PDF 解析组件按需加载
- **音频**：8 条环境音全部由振荡器、噪声缓冲与滤波器实时合成，仓库里没有一个音频文件

## 数据与隐私

- 题库、答题记录、错题、收藏、成绩、积分、账户**全部保存在浏览器 localStorage**，页面不发送任何请求给本站服务器（站点本身是纯静态托管）
- AI 答疑是唯一的对外请求：由浏览器**直接**发给你在设置里填写的服务商，本站不经手 Key 与提问内容
- 备份文件是 JSON，可下载、系统分享或复制；**不包含** AI Key
- 换浏览器、清缓存、无痕模式都会让数据消失，请定期导出备份

## 已知限制

- **纯本地存储**：没有服务器，所以没有真正的跨设备同步、没有找回密码、没有在线排行；「账户」只是本机多份数据的分隔
- **数据体检的「修复」是标记而非修改**：只把题目移出练习范围，不改题干、选项、答案、解析
- **Java 知识点分类是正则启发式**：按关键词第一条命中归类，存在误分类可能；结果页的章节统计用的是题库原始章节
- **PDF 扫描件不支持**：需要先 OCR
- **AI 讲解不保证正确**：模型可能编造细节，界面已标注仅供参考，且 AI 内容不参与判分、不可写入题库
- 部分功能入口仍在完善中（自定义字号档、评论导出等）
